# Agente de IA

Um projeto de Agente de IA desenvolvido em Python, utilizando a API do Gemini para gerar respostas inteligentes.

## obre o projeto

Este projeto tem como objetivo criar um agente capaz de receber mensagens do usuário, enviar essas mensagens para um modelo de inteligência artificial e retornar uma resposta.

O projeto está sendo desenvolvido como forma de aprendizado e prática com:

- Python
- Inteligência Artificial
- APIs
- Git e GitHub

## Segurança

A chave da API não foi disponibilizada neste repositório para manter as credenciais protegidas.

Durante o desenvolvimento, uma chave da API foi utilizada localmente para realizar os testes e verificar o funcionamento do agente. Os testes foram realizados com sucesso.

## Tecnologias utilizadas

- Python
- Gemini API
- OpenAI Python SDK
- Git
